# 📝 Code Keep

**Code Keep** is a lightweight, elegant, and dependency-free React application for managing code snippets. It provides a smooth developer experience with full CRUD operations, persistent local storage, search and sort capabilities, and an enhanced, responsive UI — all without any external libraries.

## 🚀 Features

### 🔧 Complete CRUD Functionality

- **Create** new code snippets with title, tags, and language.
- **Read/View** and display snippets in a clean layout.
- **Update** snippets via intuitive editing.
- **Delete** snippets with confirmation.

### 💾 Persistence

- **LocalStorage** keeps your snippets saved even after refreshing or closing the browser.
- **Export/Import Snippets**: Download all your snippets as a `.json` file or import them back later.

### 🔍 Smart Snippet Search

- Search by title or tags.
- Sort snippets by:
  - Date Created (Newest/Oldest)
  - Alphabetically (A–Z / Z–A)

### 📋 Clipboard Integration

- One-click copy of any snippet — just hit the copy button!

## 🖥️ Technologies Used

- ⚛️ **React** (no external libraries, just pure React)
- 🎨 **CSS Variables** for theming and styling
